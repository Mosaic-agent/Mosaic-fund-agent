# Plan: Company Deep-Dive Automation Tool

## Context

Build a CLI command `deepdive` that, given a ticker (e.g. `ADSK`), fetches primary-source data
(SEC EDGAR, XBRL, Workday job postings, yfinance) and produces a structured JSON dataset and a
7-section markdown research report. Every claim in the report traces to a raw source file cached
locally. Analysis is generated by Claude Sonnet 4.6 via the **Anthropic SDK directly** (not
LangChain) with prompt caching on the large filing text.

**Integrated into the existing `Mosaic-fund-agent` project** — not a separate repo. Autodesk (ADSK) is
the v1 target company.

    ticker: str = typer.Argument(..., help="US ticker symbol, e.g. ADSK"),

## Phase 2: Extractors (`src/deepdive/extract/`)

### `segments.py`
BeautifulSoup + lxml (already in requirements): find `<table>` where header row contains "Segment"
or ADSK segment names (AECO, Manufacturing, M&E). Extract row values → `SegmentRevenue` Pydantic
model. Fallback: regex `\$[\d,]+\s*(million|billion)` near segment name in plain text.

### `competitors.py`
1. Locate "Competition" or "Competitive" section heading in 10-K HTML via BeautifulSoup
2. Extract text block until next `<h2>`/`<h3>` sibling
3. Regex for Title Case multi-word names → `list[str]` candidates
4. Store raw section text in `FilingExcerpts.competition_section_text`

### `compensation.py`
1. Find "Summary Compensation Table" in DEF 14A HTML → NEO names, salary, bonus, stock awards, total
2. Regex `r"As of [^,]+, we (had|have|employed) approximately ([\d,]+) (full[- ]time )?(employees|people)"` → `HeadcountData`

### `jobs_signal.py`
Load `workday_jobs_raw.json` → bucket by:
- Function: classify `jobTitle` keywords (Engineering, Sales, Finance, Legal, Product, Marketing, HR, Legal, Operations)
- Location: `primaryLocation.city` + `primaryLocation.country`
- Level: keywords in `jobTitle` (Senior, Principal, Director, VP, Staff, Lead, Manager)
Return `{function: {location: count}}`

## Phase 5: Narrative Generation (`src/deepdive/analyze/narrative.py`)

**Anthropic SDK directly** — import `anthropic`, NOT `langchain_anthropic`. Uses
`settings.anthropic_api_key` (already defined in `config/settings.py`).

### Message structure (same for all 7 calls)

```python
import anthropic
from config.settings import settings

client = anthropic.Anthropic(api_key=settings.anthropic_api_key)

response = client.messages.create(
    model=settings.deepdive_model,
    max_tokens=settings.deepdive_max_tokens_per_section,
    temperature=0,
    system=[
        # Block 0: static anti-hallucination rules (~300 tokens, no cache_control)
        {"type": "text", "text": _STATIC_RULES},
        # Block 1: dataset JSON + filing excerpts — large; cached after call 1
        {"type": "text", "text": context_block_text, "cache_control": {"type": "ephemeral"}},
    ],
    messages=[{"role": "user", "content": section_task_prompt}],
)
```

The cache breakpoint on `system[1]` caches both blocks together. Calls 2–7 get cache hits
(0.10× input cost vs 1.25× write cost). 7 sequential calls complete in ~25–35s, well within the
5-minute cache TTL.

### Anti-hallucination contract (`_STATIC_RULES`)
- Every number → `[src: field_path]` citation immediately before it, dot notation matching `dataset.json`
- Missing metric → write "not disclosed" — never estimate or interpolate
- Output: pure markdown starting with section heading, 350–600 words

### 7 section specs (`SECTION_SPECS: list[dict]`)

| Key | Title | Key `dataset` fields referenced |
|-----|-------|---------------------------------|
| `core_business` | ## 1. Core Business | `segments[]`, `filing_excerpts.segment_table_text` |
| `financials` | ## 2. Financial Performance | `financials[]` (5-year P&L table) |
| `competitors` | ## 3. Competitive Landscape | `competitors_named`, `filing_excerpts.competition_section_text` |
| `investments` | ## 4. Investments & Growth | `rd_spend_usd_m`, `capex_usd_m`, `filing_excerpts.rd_section_text` |
| `execution` | ## 5. Execution Quality | `guidance_revenue_usd_m` vs `financials[-1].revenue_usd_m` |
| `valuation` | ## 6. Valuation | `valuation.*`, peer medians |
| `talent` | ## 7. Talent & Workforce | `headcount[]`, `jobs{}`, `filing_excerpts.headcount_notes_text` |

### Excerpt truncation
If `len(dataset_json) + len(all_excerpts) > settings.deepdive_context_token_budget * 3.5 chars`:
trim in priority order: `segment_table` (never cut) → `competition` (40% of remainder) →
`rd_section` (40%) → `headcount_notes` (20%).

### Error handling
- `RateLimitError`: exponential back-off, max 3 retries (1s/2s/4s) — same pattern as ofin-agent HTTP retries
- `APIConnectionError`: 1 retry
- `APIStatusError` 401/403/429: abort all remaining sections immediately
- Other: log error, store in `report.errors[section_key]`, continue to next section (partial report
  is better than none)

### Return type
`DeepDiveReport(sections: dict[str, str], errors: dict[str, str], usage_summary: dict)` where
`usage_summary` logs total tokens, cache reads, cache writes for cost visibility per run.

### Cost estimate (25k shared context tokens, claude-sonnet-4-6)
| Mode | Cost per report |
|------|----------------|
| Without caching | ~$0.59 |
| With caching | ~$0.21 |
| Savings | ~65% on input tokens |

## Pydantic Models (`src/deepdive/models.py`)

Follow exact patterns from `src/models/portfolio.py`: Pydantic v2, `Optional[float] = None`,
`Field(default_factory=list)`, no validators (use computed `@property` for derived values).

```python
from pydantic import BaseModel, Field
from typing import Optional

class SegmentRevenue(BaseModel):
    name: str
    revenue_usd_m: Optional[float] = None
    yoy_growth_pct: Optional[float] = None
    source: str = ""

class AnnualFinancials(BaseModel):
    fiscal_year: str
    revenue_usd_m: float
    gross_profit_usd_m: Optional[float] = None
    operating_income_usd_m: Optional[float] = None
    net_income_usd_m: Optional[float] = None
    free_cash_flow_usd_m: Optional[float] = None
    gross_margin_pct: Optional[float] = None
    operating_margin_pct: Optional[float] = None

class ValuationSnapshot(BaseModel):
    as_of_date: str
    pe_trailing: Optional[float] = None
    pe_forward: Optional[float] = None
    ev_revenue: Optional[float] = None
    ev_ebitda: Optional[float] = None
    fcf_yield_pct: Optional[float] = None
    peer_pe_median: Optional[float] = None
    peer_ev_ebitda_median: Optional[float] = None

class HeadcountData(BaseModel):
    period: str
    total_headcount: Optional[int] = None
    yoy_change_pct: Optional[float] = None
    notes: str = ""

class CompanyDataset(BaseModel):
    ticker: str
    company_name: str
    report_date: str
    fiscal_year_end: str
    segments: list[SegmentRevenue] = Field(default_factory=list)
    financials: list[AnnualFinancials] = Field(default_factory=list)
    valuation: Optional[ValuationSnapshot] = None
    headcount: list[HeadcountData] = Field(default_factory=list)
    rd_spend_usd_m: Optional[float] = None
    rd_pct_of_revenue: Optional[float] = None
    capex_usd_m: Optional[float] = None
    guidance_revenue_usd_m: Optional[float] = None
    guidance_eps: Optional[float] = None
    competitors_named: list[str] = Field(default_factory=list)
    jobs: dict[str, dict[str, int]] = Field(default_factory=dict)

class FilingExcerpts(BaseModel):
    segment_table_text: str = ""
    competition_section_text: str = ""
    rd_section_text: str = ""
    headcount_notes_text: str = ""
```
