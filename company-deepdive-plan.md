# Plan: Company Deep-Dive Automation Tool

## Context

Build a CLI command `deepdive` that, given a ticker (e.g. `ADSK`), fetches primary-source data
(SEC EDGAR via sec-api.io SDK, XBRL, Workday job postings, yfinance) and produces a structured
JSON dataset and a 7-section markdown research report. Every claim in the report traces to a raw
source file cached locally. Analysis is generated by invoking the **`claude` CLI binary as a
subprocess** — no Anthropic SDK or API key lives in the Python codebase; auth is owned entirely
by the claude CLI.

**Integrated into the existing `Mosaic-fund-agent` project** — not a separate repo. Autodesk (ADSK) is
the v1 target company.

## sec-api.io Class Mapping

| sec-api class | Replaces | Used for |
|---|---|---|
| `MappingApi` | raw `get_cik()` HTTP call | Ticker → CIK, company name, sector, SIC |
| `QueryApi` | `get_submissions()` + `get_filing_urls()` | Find 10-K / 10-Q / 8-K / DEF14A URLs by ticker |
| `DownloadApi` | `fetch_filing_html()` | Download actual filing HTML to cache (200+ req/s) |
| `XbrlApi` | entire `xbrl.py` XBRL parsing | `xbrl_to_json(htm_url=...)` → standardized P&L, balance sheet, cash flows |
| `ExtractorApi` | `extract/segments.py` + `extract/competitors.py` | `get_section(url, "7", "html")` for segment MD&A; `get_section(url, "1", "text")` for business/competition |
| `ExecCompApi` | `extract/compensation.py` DEF14A HTML scraping | Structured NEO comp table by ticker — no HTML parsing needed |

All six classes use `settings.sec_api_key`. Free tier available at sec-api.io/signup.

def deepdive(
    ticker: str = typer.Argument(..., help="US ticker symbol, e.g. ADSK"),
    date: str = typer.Option(None, "--date", "-d", help="Report date YYYY-MM-DD (default: today)"),

## Phase 1: EDGAR Source (`src/deepdive/sources/edgar.py`)

Cache-first pattern — mirrors `src/importer/fetchers/cot_fetcher.py`: stateless functions,
write raw blob to disk on first call, read from disk on re-run. Never re-fetches if cache file
exists.

```python
from sec_api import MappingApi, QueryApi, DownloadApi
from pathlib import Path
from config.settings import settings

def lookup_company(ticker: str, cache_dir: Path) -> dict:
    """
    MappingApi.resolve("ticker", ticker) → cache_dir/company_meta.json
    Returns {cik, company_name, sic, sector, exchange}.
    Raises ValueError if ticker not found.
    """

def find_filings(ticker: str, form_types: list[str], cache_dir: Path) -> list[dict]:
    """
    QueryApi.get_filings({"query": f'ticker:{ticker} AND formType:"{form_type}"', ...})
    → cache_dir/filings_index.json
    Returns list of {form_type, filed_date, filing_url, accession_no}.
    """

def download_filing(url: str, local_path: Path) -> str:
    """
    DownloadApi.get_file(url) → write to local_path. Return cached content if file exists.
    """
```

**Error handling:** `try/except Exception`, `log.warning(...)`, return empty dict/string, never crash.

**Files to fetch for v1:**
- Latest 10-K → `10-K-{filed_date}.htm`
- Last 4 10-Qs → `10-Q-{filed_date}.htm`
- Last 12 8-Ks → `8-K-{filed_date}.htm`
- Latest DEF 14A → `DEF14A-{filed_date}.htm`

## Phase 6: Narrative Generation (`src/deepdive/analyze/claude_cli.py`)

**`claude` CLI binary invoked as subprocess** — no `anthropic` Python SDK. Auth is owned entirely
by the claude CLI (`claude auth` run once by the user).

```python
import shutil, subprocess
from pathlib import Path
from config.settings import settings

def _check_claude_binary() -> str:
    path = shutil.which(settings.claude_cli_path)
    if not path:
        raise RuntimeError(
            f"claude CLI not found at '{settings.claude_cli_path}'. "
            "Install it from https://claude.ai/download, then run 'claude auth'."
        )
    return path

def generate_section(section_key: str, dataset_json: str, prompts_dir: Path) -> str:
    """
    Build prompt = static anti-hallucination rules + dataset_json + section task from
    prompts/<section_key>.txt. Call claude CLI subprocess. Return stdout as markdown.
    Retry up to 3× on non-zero exit (1s / 2s / 4s back-off).
    """
    claude = _check_claude_binary()
    prompt_template = (prompts_dir / f"{section_key}.txt").read_text()
    full_prompt = f"{_STATIC_RULES}\n\n---\n\n{dataset_json}\n\n---\n\n{prompt_template}"
    for attempt in range(3):
        result = subprocess.run(
            [claude, "-p", full_prompt],
            capture_output=True, text=True, timeout=120
        )
        if result.returncode == 0:
            return result.stdout
        time.sleep(2 ** attempt)
    raise RuntimeError(f"claude CLI failed for section '{section_key}' after 3 attempts")
```

### Prompt templates (`src/deepdive/analyze/prompts/<section>.txt`)

Plain text files — editable without touching Python code.

### Anti-hallucination rules (`_STATIC_RULES`)
- Every number → `[src: field_path]` citation immediately before it, dot notation matching `dataset.json`
- Missing metric → write "not disclosed" — never estimate or interpolate
- Output: pure markdown starting with section heading, 350–600 words

### 7 sections

| Key | Title | Key `dataset` fields referenced |
|-----|-------|---------------------------------|
| `core_business` | ## 1. Core Business | `segments[]`, `filing_excerpts.segment_table_text` |
| `financials` | ## 2. Financial Performance | `financials[]` (5-year P&L table) |
| `competitors` | ## 3. Competitive Landscape | `competitors_named`, `filing_excerpts.competition_section_text` |
| `investments` | ## 4. Investments & Growth | `rd_spend_usd_m`, `capex_usd_m`, `filing_excerpts.rd_section_text` |
| `execution` | ## 5. Execution Quality | `guidance_revenue_usd_m` vs `financials[-1].revenue_usd_m` |
| `valuation` | ## 6. Valuation | `valuation.*`, peer medians |
| `talent` | ## 7. Talent & Workforce | `headcount[]`, `jobs{}`, `filing_excerpts.headcount_notes_text` |

## Pydantic Models (`src/deepdive/models.py`)

Follow exact patterns from `src/models/portfolio.py`: Pydantic v2, `Optional[float] = None`,
`Field(default_factory=list)`, no validators.

```python
from pydantic import BaseModel, Field
from typing import Optional

class SegmentRevenue(BaseModel):
    name: str
    revenue_usd_m: Optional[float] = None
    yoy_growth_pct: Optional[float] = None
    source: str = ""

class AnnualFinancials(BaseModel):
    fiscal_year: str
    revenue_usd_m: float
    gross_profit_usd_m: Optional[float] = None
    operating_income_usd_m: Optional[float] = None
    net_income_usd_m: Optional[float] = None
    free_cash_flow_usd_m: Optional[float] = None
    gross_margin_pct: Optional[float] = None
    operating_margin_pct: Optional[float] = None

class ValuationSnapshot(BaseModel):
    as_of_date: str
    pe_trailing: Optional[float] = None
    pe_forward: Optional[float] = None
    ev_revenue: Optional[float] = None
    ev_ebitda: Optional[float] = None
    fcf_yield_pct: Optional[float] = None
    peer_pe_median: Optional[float] = None
    peer_ev_ebitda_median: Optional[float] = None

class HeadcountData(BaseModel):
    period: str
    total_headcount: Optional[int] = None
    yoy_change_pct: Optional[float] = None
    notes: str = ""

class CompanyDataset(BaseModel):
    ticker: str
    company_name: str
    report_date: str
    fiscal_year_end: str
    segments: list[SegmentRevenue] = Field(default_factory=list)
    financials: list[AnnualFinancials] = Field(default_factory=list)
    valuation: Optional[ValuationSnapshot] = None
    headcount: list[HeadcountData] = Field(default_factory=list)
    rd_spend_usd_m: Optional[float] = None
    rd_pct_of_revenue: Optional[float] = None
    capex_usd_m: Optional[float] = None
    guidance_revenue_usd_m: Optional[float] = None
    guidance_eps: Optional[float] = None
    competitors_named: list[str] = Field(default_factory=list)
    jobs: dict[str, dict[str, int]] = Field(default_factory=dict)

class FilingExcerpts(BaseModel):
    segment_table_text: str = ""
    competition_section_text: str = ""
    rd_section_text: str = ""
    headcount_notes_text: str = ""
```
